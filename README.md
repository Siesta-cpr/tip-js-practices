## Задание 1. Один файл — две среды выполнения

Файл запущен в Node.js (`node practice-01/js/hello.js`, вывод в терминале):

    Студент: Илья
    Группа: ЭФБО-13-25

    JavaScript успешно запущен
    Тип document: undefined

В браузере (Safari, через `index.html`, вывод в консоли DevTools) те же строки, кроме последней:

    Тип document: object

Объяснение: `document` — часть браузерного DOM API. В Node.js такого глобального объекта нет, поэтому `typeof document` возвращает `"undefined"`. В браузере `document` существует всегда, поэтому тип — `"object"`.

## Задание 2. Исследование типов и преобразований

| Выражение | Ожидание | Фактический результат | Тип | Объяснение |
|---|---|---|---|---|
| `"8" + 2` | `"82"` | `82` | string | `+` со строкой — конкатенация |
| `"8" - 2` | `6` | `6` | number | `-` приводит операнды к числу |
| `Number("8") + 2` | `10` | `10` | number | явное приведение перед сложением |
| `"12" > "3"` | `false` | `false` | boolean | сравнение строк идёт посимвольно |
| `12 === "12"` | `false` | `false` | boolean | строгое равенство без приведения типов |
| `Number("")` | `0` | `0` | number | пустая строка → 0 |
| `Number("text")` | `NaN` | `NaN` | number | нечисловая строка не преобразуется |
| `Boolean("false")` | `true` | `true` | boolean | любая непустая строка truthy |
| `typeof null` | `"object"` | `object` | string | историческая особенность JS |
| `typeof NaN` | `"number"` | `number` | string | NaN относится к типу number |
