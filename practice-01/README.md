# Практическая работа № 1

## Задание 1. Один файл — две среды выполнения

Файл `js/hello.js` был запущен двумя способами:

1. **Node.js** — командой `node practice-01/js/hello.js` из корня репозитория. Вывод появился в терминале.
2. **Браузер** — файл `index.html` открыт напрямую, скрипт подключён через `<script src="./js/hello.js" defer>`. Вывод появился во вкладке Console инструментов разработчика (не на странице).

### Различие последней строки

- В Node.js: `Тип document: undefined`
- В браузере: `Тип document: object`

Объяснение: `document` — это глобальный объект, предоставляемый браузерным DOM API. В окружении Node.js браузерного окна и DOM нет, поэтому переменная `document` не объявлена, и `typeof document` возвращает `"undefined"`. В браузере же `document` существует как часть глобального объекта `window`, поэтому `typeof document` возвращает `"object"`.
