## Отладка

Точка останова установлена на строке `const rawId = card.dataset.taskId;` в `handleTaskListClick` (`main.js`, строка 64). Подтверждено скриншотом остановки на этой строке. Значение `rawId` на момент остановки — строка (тип `string`); после перехода на следующую строку (`const id = Number(rawId);`) значение становится числом (тип `number`).

Иллюстрация: `screenshots/debug-breakpoint.png`

## Вывод

Реализовано отображение задач через DOM-методы без `innerHTML`, делегирование событий через `closest`, различение `event.target`/`event.currentTarget` при всплытии, фильтрация без потери скрытых записей (полный массив и видимая выборка хранятся раздельно), раздельный расчёт общей сводки (по всему списку) и счётчика «Показано» (по видимой выборке). Названия задач выводятся как текст (`textContent`), что подтверждено экспериментом с `<strong>` — HTML-тег не создаётся, виден только текст со скобками.

Наиболее показательная сложность — различие строкового `dataset.taskId` и числового идентификатора: без явного преобразования через `Number()` и проверки `Number.isSafeInteger` некорректное значение (например, `"4abc"`) могло бы попасть в прикладную логику и привести к необработанной ошибке; проверка на границе обработчика предотвращает это и выводит понятное сообщение без изменения данных.
